# Developer Portfolio

This is a static HTML, CSS, and JavaScript portfolio template. To publish with
GitHub Pages, copy the contents of this folder into the root of your Pages
repository and enable Pages for that branch. No build step is required for
GitHub Pages; `index.html` and its relative asset links work from a repository
subpath too.

## Make it yours

- Replace the bracketed placeholder text and example links in `index.html`.
- Put your portrait, project previews, workplace photo, and certificate images
  in `images/`, then update the matching `src` paths and alt text.
- Duplicate a project card or timeline row to add more work and qualifications.
- Change the color and typography variables at the top of `css/styles.css`.
- The social icons are inline SVGs. Update their links and labels in
  `index.html`.
- `fonts/README.md` explains how to add local fonts. The `scss/` folder is
  optional; the published page uses `css/styles.css` directly.

The Replit preview uses Vite, but the website itself has no framework or
backend dependency.
